# D4e-1 — annexe des calendriers complets

Données synthétiques, aucune activation. A : référence ; Bm : mécanique, sans filtre de dossier ; Bc : conditionnelle aux critères proposés, toujours non autorisée en application. Les 19 scénarios couvrent chacun 56 jours.

F = facile, I = fractionné, S = soutenue, H = côtes, V = variations, L = longue, R = récupération. Les quatre structurées partagent toujours une protection. Le nombre après le type indique les minutes. « — » : aucune sélection ; « × » : jour indisponible. Les détails des types admissibles, références, motifs, activités et bilans sont reproductibles dans `/tmp/d4e1-calendars.json` avec la commande du rapport.

La colonne Bc indique le paramétrage quotidien de laboratoire (structurées/longues), jamais un réglage de production. Les scénarios de suivi supposent explicitement les réalisations synthétiques déclarées ; la projection n’en déduit aucune.
