# Contribuer à runKLMrun

Merci de votre intérêt pour runKLMrun !

## Conventions de commits

Le projet utilise les Conventional Commits.

Les descriptions des commits sont rédigées en français.

| Type | Utilisation |
|------|-------------|
| feat | Nouvelle fonctionnalité |
| fix | Correction de bug |
| refactor | Réorganisation du code |
| perf | Amélioration des performances |
| docs | Documentation |
| test | Ajout ou modification de tests |
| style | Mise en forme du code |
| chore | Maintenance du projet |
| ci | Intégration et déploiement |

### Exemples

- `feat: ajout de l'analyse des entraînements`
- `fix: correction du calcul des allures`
- `docs: mise à jour du guide utilisateur`
- `perf: optimisation du chargement de l'historique`

## Versionnement

runKLMrun utilise le versionnement sémantique :

MAJEUR.MINEUR.CORRECTIF

- MAJEUR : changement incompatible.
- MINEUR : nouvelle fonctionnalité compatible.
- CORRECTIF : correction de bug compatible.

## Changelog

Les évolutions importantes sont documentées dans CHANGELOG.md.

Avant chaque publication :
1. Mettre à jour le numéro de version.
2. Compléter CHANGELOG.md.
3. Exécuter les tests.
4. Vérifier la compilation.
5. Effectuer le commit et le push.
6. Créer le tag correspondant à la version.

## Confidentialité

Ne jamais ajouter au dépôt :
- Des archives Polar personnelles.
- Des fichiers contenant des parcours GPS privés.
- Des données de santé personnelles.
- Des identifiants ou secrets.
